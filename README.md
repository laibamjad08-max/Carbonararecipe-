# Authentic Spaghetti Carbonara: The Complete Guide

A responsive, single-page article about authentic Roman spaghetti carbonara, built with HTML and CSS.

## Live Demo

https://laibamjad08-max.github.io/Carbonararecipe-/

## About the Project

This project is a complete guide to making traditional carbonara. It covers:

- Introduction and history of the dish
- Ingredients and step-by-step instructions
- Expert tips and common mistakes to avoid
- Popular variations
- Frequently Asked Questions (FAQs)

## Features

- Clean, modern design with a hero banner
- Fully responsive (works on mobile, tablet and desktop)
- Dark mode support
- SEO-friendly headings and meta description
- Image sections with alt text and captions

## Technologies Used

- HTML5
- CSS3
- GitHub Pages (hosting)

## How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.
